# Touchtrack logo

`touchtrack-logo.png` is the primary transparent raster logo for the repository README. Its rounded strip represents the Touch Bar; the play button and audio strokes represent music playback.

Generated with the built-in image generation tool. `touchtrack-app-icon.png` adapts the logo to a dark rounded square. Tauri generates the application icon set in `src-tauri/icons/` from this source.

## App icon edit prompt

```text
Edit the reference Touchtrack logo into a production macOS application icon. Preserve the recognizable red horizontal capsule, central play triangle and symmetric audio strokes. Clean up all stray speckles and rough edges, make shapes crisp and precise. Place the red symbol centered on a solid near-black rounded square app tile with generous padding; symbol width 78% of tile, retain its wide slim proportions. Square 1024x1024 canvas, rounded square tile occupies 88% canvas width and height with transparent space outside its rounded corners. Flat graphic, no text, no perspective, no shadow, no mockup, no additional symbols. The reference is the logo to preserve.
```

## Generation prompt

```text
Primary request: Create one exceptionally clean, distinctive flat logo symbol, no text. A thin horizontal rounded Touch Bar capsule with a rhythmic track running through it: a small play triangle integrated into three ascending and descending rounded audio strokes, visually unified as one compact mark. Should suggest touch interaction and music, not a generic headphones logo.
Style: precise geometric brand design, vector-like solid silhouettes, balanced negative space, excellent small-size legibility. Restrained vivid coral-red mark, no gradients. Wide symbol centered with generous transparent padding on square canvas, occupying about 75% width. Transparent background.
Constraints: one logo only, no wordmark, no lettering, no mockup, no keyboard illustration, no shadows, no 3D, no YouTube logo, no Apple logo.
```
